## What changed

1. **Now eats the frozen 40 ms tensor** (`data/processed/5c0c560e__stimOn_pre400_post800_bin40_rate1.npz`)
   via `load_processed`, instead of building its own [-0.5,+0.8] s / 50 ms tensor. This closes
   one of the "three notebooks, three preprocessings" inconsistencies flagged in the synthesis
   doc (§0). Units are now the ≥1 Hz set (VISp 19 / SCm 44 / MRN 54), pre_s 0.4 s, 30 bins.
2. **MSR demoted to a *comparison set*.** It is still computed (on the kept units, aligned to
   the tensor columns via `keep_idx`, with a re-binning **assert** so a mis-alignment can't
   silently mislabel a unit), and the top-half `msr_top` is carried alongside `all` — but only
   to *show* the effect of the cut on the geometry, not as a recommended population. A printed
   reminder points at the not-adopted decision.
3. **The visualisations are now the deliverable: PCA, dPCA, MDS, Laplacian eigenmaps in 3-D,
   coloured by time.** Two window views, both requested:
   - **post-stimulus** (`3d_post_<region>.png`) — cividis, t ∈ [0, 0.8] s.
   - **full window incl. pre-stimulus** (`3d_prestim_<region>.png`) — a **diverging** map
     centred at stimulus onset (`RdBu_r`, CVD-safe): **blue = baseline, red = evoked**. The
     two views share one embedding (fit on the full window), so the prestim view actually
     shows the population **leaving** its baseline region rather than comparing two separate
     fits. In SCm/MRN the baseline points sit in a tight clump at one end of the PCA "V" and
     the Laplacian arc; the evoked points fan out along the path — a clean visual departure.
   - **dPCA** (`3d_dpca_demixed.png`) — the leading time/stimulus/decision demixed axes, the
     four stimulus×decision condition means drawn as trajectories, colour = time, shape =
     condition. Trajectories are **display-smoothed** (σ=1 bin) because the cells hold only
     K=25 trials; the variance %s in the labels are from the unsmoothed fit. The
     **decision-axis variance rises VISp 1% → SCm 3% → MRN 9%** — the project's gradient,
     now visible as geometry (the conditions separate on the decision axis only in the motor
     areas). All units only (dPCA is trial-limited; halving units would just add noise).
4. No choice-coloured scatter (that split lives in nb 04 / the worklog), per request.

## Update — 3-D plots made INTERACTIVE (Plotly)

The 3-D figures were converted from static matplotlib to **Plotly** so they can be rotated
(drag) and zoomed (scroll). Chosen over `%matplotlib widget`/ipympl because the Plotly scene
**persists in the notebook output** and renders in VSCode without re-running, and because it
survives kernel shutdown. Renderer set to `plotly_mimetype+notebook_connected` (VSCode reads
the mimetype offline; classic Jupyter falls back to a CDN). Each 3-D figure is also exported to
`results/figures/phase3_dimred/*.html` (self-openable in a browser; `include_plotlyjs="cdn"` so
the files stay ~40 KB). The **2-D** charts (`dpca_variance_split`, `rrr_communication`) stay
static matplotlib PNG. CVD-safe colourscales preserved: **Cividis** (time) and **RdBu +
reversescale** (diverging, blue=baseline/red=evoked). `plotly` was dry-run-verified additive
before install (only `plotly-6.9.0`; deps already present). Stale 3-D PNGs from the matplotlib
version were deleted.
